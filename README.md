gamas

Make a blank codespace and install the live server extension. afterwards you should use the terminal to unzip each game file and remove the remaining zip file. e.g:
unzip n-gon-master.zip
rm n-gon-master.zip
after you are done unziping each gama you can press the go live button in the bottom right and it should open a new tab with a list of all the games
