## gamas

Make a blank codespace and install the Live Server extension.
Afterwards, you should use the terminal to unzip each game file and remove the remaining zip file. e.g:
```
unzip n-gon-master.zip
rm n-gon-master.zip
```
After you are done unzipping each gama you can press the <ins>Go Live</ins> button in the bottom right, and it should open a new tab with a list of all the games
